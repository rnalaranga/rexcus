2. Detailed Clause-by-Clause Gap Analysis

Clause 7.1.5 — Calibration of Measuring Instruments (Critical Non-Conformance)

High Priority (P0)
ISO 9001:2015 Mandatory Requirement: All measuring equipment used to certify conformity (Micrometers, Verniers, Bore Gauges, CMM, Dial Indicators) must be uniquely identified, calibrated at specified intervals, and safeguarded against adjustments that would invalidate the measurement.
Current System State:

In WorkOrderQCHub.tsx, inspectors select instruments from hardcoded text strings (e.g., External Micrometer (0-25mm)). No tool serial number or calibration status is recorded.

Audit Finding / Risk:

If an uncalibrated instrument with wear or drift is used on an h7 precision shaft, defective parts can pass internal QC, resulting in customer rejection and ISO audit non-conformance.

Action Required: Create calibration_instruments table. In WorkOrderQCHub.tsx, dropdown must pull active calibrated instruments and block/warn if calibration certificate has expired.

Clause 8.7 & 10.2 — Non-conforming Outputs (NCR) & CAPA (Critical Non-Conformance)

High Priority (P0)
ISO 9001:2015 Mandatory Requirement: The organization must identify and control nonconforming outputs to prevent their unintended use or delivery, take appropriate disposition action (rework, scrap, concession), and initiate Corrective and Preventive Actions (CAPA) addressing root cause.
Current System State:

Failed QC measurements log into rework_logs, but there is no formal serial-numbered Non-Conformance Report (NCR) document or formal CAPA root-cause inquiry.

Audit Finding / Risk:

Without root-cause analysis (5-Why or 4M Fishbone), repetitive machine setting or tooling mistakes recur, increasing material scrap and machining hour losses.

Action Required: Implement automated NCR generation when QC status is marked "Fail". Require disposition decision (Rework, Scrap, Customer Concession) and 5-Why root cause log before closing the job.

Clause 8.4 — Vendor Evaluation & Incoming Material MTR (Medium Non-Conformance)

Medium Priority (P1)
Current System State:

Vendors are selected via SupplierAutocomplete with ledger tracking. GRN records material description and condition (Good/Damaged/Rejected).

Audit Finding / Risk:

Lacks Mill Test Certificate (MTR) and Heat Number tracking for raw steel/alloys. Lacks automated vendor scoring (On-Time Delivery % & Rejection %).

Action Required: Add Heat Number / Batch No and MTR document attachment in GRNBuilder.tsx. Calculate automated vendor delivery & quality scorecards in Suppliers.tsx.

Clause 7.1.3 — Machine Maintenance (TPM) Schedules & Breakdown Tickets

Medium Priority (P2)
Current System State:

Machinery registry records machine list, hourly rate, and single lastMaintenance date.

Audit Finding / Risk:

No Preventive Maintenance (PM) intervals (daily, 500-hr, quarterly). No Mean Time to Repair (MTTR) or breakdown downtime logging.

Action Required: Create machine_maintenance_logs table with scheduled PM calendar and breakdown maintenance ticket workflow.
